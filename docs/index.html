    02 / THE MECHANISM

    Split carefully.
    Merge immediately.

    A finite free list and checked offsets. No magic pointers. The allocator handles the same actual bytes that the workbench reads.

    01 / PLACE

    Choose a fitting span.

    First fit picks the lowest-address free span that fits after alignment. Best fit picks the smallest full free span that fits, with lower address breaking ties.

    02 / SPLIT

    Keep the remainder.

    Round requested capacity to 8 bytes. Leave any alignment prefix and trailing space on the free list. All allocation bytes begin at zero.

    03 / RESIZE

    Preserve the prefix.

    Shrink, grow into an adjacent free span, or move. Successful resize always returns a fresh handle; failure keeps the old bytes and handle intact.

    04 / RETURN

    Leave no gap between gaps.

    Free zeroes the span and merges free neighbors on both sides. Stale and foreign handles are rejected. Adjacent free spans never remain separate.

    Free bytes ≠ one free span.

    Four 32-byte gaps cannot satisfy a 64-byte allocation. Even a large gap may not fit after alignment. This is external fragmentation, not a hidden memory leak.

    03 / KNOW THE BOUNDARY

    A suballocator.
    Not a system allocator.

    The native Python library manages a bytearray. The browser independently manages a Uint8Array. Both allocate, copy, read and erase actual bytes inside a fixed arena. Neither provides native addresses or replaces malloc.

    Read the implementation ↗
    Checked API, not isolation
    Handles use exact object identity, not forgeable offset values, but this is trusted in-process code. Direct access, reflection, threads, hostile objects and native memory corruption are outside the contract.
    Finite space and metadata
    Library arena 32..4096 bytes, multiple of 8. Relative alignment 1..64, powers of two. Metadata lives outside the arena, so reported free space excludes metadata overhead. Handle issuance is capped at 65535 per arena.
    Zeroing is not secure erasure
    Freed arena bytes and padding are zeroed; copies returned by reads and host runtime copies may remain elsewhere. Reset loses all live allocations. Do not enter secrets.
    No hidden machinery
    No garbage collector, compaction, thread safety, virtual memory, OS page allocation, file writes, network, storage, uploads or telemetry. This is not a memory benchmark or a production memory-safety guarantee.
